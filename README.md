# CQRS task demo

Небольшой учебный пример CQRS на Spring Boot и Java 17. Команды изменяют состояние задач, а запросы читают отдельную read-модель. Проекция обновляется напрямую в памяти; цель — показать принцип, а не делать production-архитектуру.

Полное описание принципа, элементов проекта и запуска — в файле `start.txt`.

Быстрый запуск:

```bash
gradle bootRun
```
